# Qalun UX/UI audit and revamp recommendation

Date: 2026-10-13. Scope: every screen of the Qalun desktop app on master (v0.2.0):
the home window (job list, new-job form, running state), the review window
(recitation and lecture), the Look panel, and the Export, Episode and Ayah
dialogs, in English and Arabic, light and dark.

Method: the GUI code under `src/qurantext/gui/` was read in full, and every
screen was rendered offscreen with the Fusion style in a light and a dark
palette. The screenshots are in the session scratchpad
(`scratchpad/shots/*.png`): `home-light.png`, `home-light-more.png`,
`home-light-running.png`, `home-dark.png`, `home-ar.png`,
`review-recitation-light.png`, `review-recitation-dark.png`,
`review-recitation-light-customise.png`, `review-lecture-light.png`,
`review-recitation-ar.png`, `export-light.png`, `episode-light.png`,
`ayah-picker-light.png`. The script that makes them is `scratchpad/shots.py`
and can be re-run after any change.

## 1. Verdict in one paragraph

The app is functionally mature and unusually careful about behaviour
(RTL, contrast-checked amber, keyboard shortcuts on physical keys, undo for
every edit, no-GIL-hold waits). What makes it feel plain is that it has **no
visual layer of its own**: it is raw Qt Fusion with one font size, one weight
for headings, no icons, no app icon, no spacing system, no surfaces, and no
visual emphasis on the one action each screen exists for. The fix is not a
redesign of the workflows, which are sound, but a **presentation layer**
(tokens, a stylesheet, icons, a small set of composite widgets) plus **two
layout corrections** in the review window and a **hierarchy pass** on the
home window. Everything below is ordered by impact.

## 2. Findings

Severity: **High** = costs the user time or understanding every session;
**Medium** = makes the app feel unfinished; **Low** = polish.

### 2.1 Cross-cutting (apply everywhere)

| # | Finding | Severity | Evidence |

### 2.5 What already works and must survive the revamp

- Amber / playhead red chosen per palette lightness, every colour ≥ 4.5:1 (`gui/colors.py`).
- Full RTL mirroring with the timeline fixed right-to-left in both languages.
- Buddies on every label, tooltips with shortcuts, keyboard alternatives to every drag.
- Wheel-safe sliders and combos inside the scroll area.
- Undo for every edit including look changes; dirty title asterisk; close prompt.
- 2 109 tests addressing widgets by attribute name (`win.new_job.start_button` …). The revamp must keep those names.

## 3. Design direction

Searches in the ui-ux-pro-max database returned web-landing-page systems, not a
desktop-tool match, so the direction below is built from the app's own
content and the database's style entry that fits ("Soft UI Evolution": subtle
depth, measured contrast, visible focus, 200–300 ms motion). Treat it as a
recommendation, not a database match.

**Principle: the app should look like the videos it makes.** The default look,
Night gold, is deep ink with a gold highlight and a cream card. Borrow that
family for the chrome so the preview, the swatches and the window feel like
one product.

### 3.1 Tokens (one module, `gui/theme.py`)

| Token | Light | Dark | Use |
|-------|-------|------|-----|
| `surface.window` | #F4F3F0 | #1C1B1A | window background (warm, not Fusion's #EFEFEF / #353535) |
| `surface.panel` | #FFFFFF | #262523 | cards, panes, table base |
| `surface.raised` | #FFFFFF + 1 px #E2DFD8 + 0/1/2 shadow | #2E2C29 + 1 px #3A3835 | drop zone, job row, dialog sections |
| `text.primary` | #1C1B1A | #ECE9E3 | body (≥ 12:1) |
| `text.secondary` | #5F5B55 | #A8A49C | detail lines, helper text (≥ 4.6:1) |
| `accent` | #2F5D8A | #7FB0E6 | primary buttons, selection, links, focus ring |
| `attention` | existing amber #9E5600 | existing #EF9F27 | Needs review, edited word bar (unchanged) |
| `playhead` | existing #C83030 | existing #E24B4A | unchanged |
| `gold` | #B8891C | #D9B45B | one decorative accent: app icon, section rules, swatch ring |
| radius | 6 px (controls), 10 px (cards) | | |
| spacing | 4 / 8 / 12 / 16 / 24 / 32 | | 8-pt grid |
| type | 15 pt semibold window title · 12 pt semibold section · 10 pt body · 9 pt secondary · 13 pt mono-tabular clock | | QFont with `setPointSizeF`, tabular digits for times |

Implementation: one `QPalette` per theme set on the `QApplication`, a `QSS`
string generated from the tokens (so RTL and dark need no separate sheet), a
`Prefs.theme` of `system | light | dark`, and a `warning_color()` /
`playhead_color()` that keep working because they read palette lightness.

### 3.2 Icons

Bundle **Lucide** (ISC licence, add to `THIRD_PARTY_NOTICES.md`) as SVG,
tinted at load time with the palette's text / accent colour through
`QtSvg` (in PySide6-Essentials, already shipped). 16 px in rows and tables,
20 px in toolbars. Needed set (≈ 30): play, pause, skip-back, skip-forward,
scissors, undo, redo, save, check-circle, trash, download, film, sparkles
(episode), palette, image, sun, moon, monitor, refresh, folder-open, folder,
x, chevron-right/down/left, search, info, alert-triangle, pencil, link,
qr-code, settings, globe.

Add an **app icon** (a gold ayah-end roundel on ink, 1024 px master → .ico /
.icns / .png) and set it on every window and on the PyInstaller spec.

### 3.3 Composite widgets to add (each small, each tested once)

- `PrimaryButton` — filled accent, white text, 36 px tall, focus ring.
- `SectionHeader` — 12 pt semibold + optional trailing action.
- `Card` — raised surface with 16 px padding; used by the drop zone, each job row, each Episode part.
- `StatusChip` — pill with icon + text in attention / accent / secondary colours; replaces amber-only text.
- `Banner` — non-modal, dismissible, with icon and optional action button; replaces the warnings label and the render/finished message boxes.
- `TimeRuler` — ticks and mm:ss labels bound to the existing `Viewport`.
- `ShortcutSheet` — a `?`-triggered overlay listing every binding.

## 4. Revamp, screen by screen

### 4.1 Home window

1. **Header bar** (48 px): app icon + "Qalun" at 15 pt; right side: theme toggle, language, settings gear, help. Removes the footer.
2. **Settings dialog** gathers Quran text, output folder, transcription engine (with the token note), default look, episode defaults, language, theme and log folder. "More options" shrinks to the per-job choices: subtitles and "Render right away".
3. **Form as a column of max 560 px**, left-aligned in the right pane, not stretched to the window. Drop zone becomes a `Card` with an upload-cloud icon, the sentence, and a real "Choose a file" secondary button; once a file is chosen the card shows a file icon, name, folder and duration.
4. **Mode toggle** stays a segmented control but gets an icon per mode (mic for recitation, book-open for lecture) and a one-line description under it that changes with the mode ("Times the ayat of a recitation" / "Finds the ayat quoted in a lecture"). This is the onboarding.
5. **Start** becomes a `PrimaryButton` the full width of the form; the blocking reason moves under it in secondary text with an info icon. While running, Start turns into a progress button (bar inside it, "Cancel" beside it) and the separate full-width bar goes; the job row keeps its 6 px bar.
6. **Job list**: rows become `Card`s with a 48 px thumbnail (last rendered frame, or the mode icon on the look's background colour), name, `StatusChip`, detail line, and a relative date. Hovering shows Open / Show in folder / Remove as icon buttons on the row; the button row under the list stays for keyboard and Arabic users but is otherwise hidden. The list watches its folders with `QFileSystemWatcher`; Refresh becomes an icon in the pane header.
7. **Empty state**: an illustration (ayah-end roundel on a faint waveform), "No jobs yet", and the two mode descriptions as cards that pre-select the mode when clicked.

### 4.2 Review window

1. **Layout** (the biggest single gain): two columns instead of three-over-one.
   - Left column (fixed width = preview width + 32): preview on top, below it a tab strip "Look | Cards" — Look holds today's panel; Cards holds the ayah rows of the segment list. The preview gains a "fit / 100 %" toggle and a double-click full-size view.
   - Right column: time ruler, waveform, word strip, transport, selection bar, then the **caption table filling the remaining height**. The `addStretch` goes. In a recitation (no captions) the right column shows the ayah rows there instead and the Cards tab is hidden.
2. **Toolbar** grouped with separators and icons: [Save] [Undo] [Redo] | [Mark as reviewed] [Remove] | *stretch* | [Surah on the cards ▾] [Episode ✦] [Export ⤓] [**Render** ▶ primary]. Render shows a progress ring inside the button while rendering; Cancel appears beside it.
3. **Time ruler** above the waveform (24 px): major ticks every 1/5/10/30 s depending on span, labels in tabular digits, hover shows the time under the pointer; a click seeks. The zoom slider shows its span ("20 s shown") and gets `−` / `+` icon buttons.
4. **Waveform**: accent-coloured bars on `surface.panel`, 50 % opacity outside the current word, full inside it; gap bands hatched in attention colour; playhead 2 px with a small triangle on the ruler.
5. **Word strip**: 4 px radius boxes, selected = accent fill, under-playhead = 2 px accent outline, edited = 3 px attention top bar (kept), hover handle widened to 6 px. Minimum box height 40 px.
6. **Transport** with icons: ⏮ word ⏯ ⏭ word, the clock in 13 pt tabular digits, rate as a segmented 1× / 0.75× / 0.5×, then the nudge group (−50 / snap / +50) moved here from the selection bar so every time control sits on one row. The selection bar keeps only the word and its span, in 12 pt Arabic.
7. **Warnings** become a `Banner` with reserved height (collapses to a 4 px rule when empty, so nothing jumps) and a count ("2 gaps ▸") that expands.
8. **Shortcuts**: `?` and a toolbar help icon open the `ShortcutSheet`; the status bar line stays but shows only the three most useful bindings.
9. **Segment table**: 32 px rows, striped, Ayah cell with a mushaf icon for cards and a mic icon for captions, hand-placed cards with a pencil icon, "Retimed words" rendered as a small count chip only when > 0, current row with an accent left rule rather than full highlight so Arabic text keeps its colour.
10. **After a render**: a `Banner` "Rendered furquanTra7-11.mp4 · 1 m 36 s" with Play and Show in folder; the preview pane shows a film icon overlay on hover that plays the file with the system player.

### 4.3 Look panel

Same controls, re-flowed: swatches as 56×36 tiles with a 2 px gold ring on the chosen one and the name under it; Customise as a 2-column grid of colour rows (chip 24 px + name) with the hex shown; every slider with a value readout at its end; Background kind as icon tiles (solid, gradient, stars, lattice, arches, image) rather than a combo; "Use for new videos" and "Reset" as a secondary and a text button at the bottom.

### 4.4 Dialogs

- **Episode**: a horizontal strip of four `Card`s — Intro · Recitation · Lecture (fixed, with its length) · Outro — each with a kind picker (None / My clip / Generated), its preview thumbnail (the dialog already renders previews) and its length; the total under the strip. The tracked link and QR stay as they are (they are the measurable part).
- **Export**: add a one-line description under each format; show "needs a render" beside the disabled radio instead of only a tooltip.
- **Ayah picker**: unchanged; apply the type scale.

## 5. Plan, effort and risk

| Phase | Content | Effort | Risk to tests |
|-------|---------|--------|---------------|
| A. Foundation | `gui/theme.py` tokens + palettes + QSS, theme pref, app icon, Lucide bundle + `icon()` helper, `PrimaryButton`, `SectionHeader`, `Card`, `StatusChip`, `Banner`. Applied app-wide but no layout changes. | 3–4 days | Low: widget names unchanged; `test_colors` extended for the new palettes |
| B. Home | Header bar, Settings dialog, form column, Start as primary/progress, job cards + watcher, empty state. | 3–4 days | Medium: `test_home_panels` rows and More options move; keep `new_job.*` attribute names |
| C. Review layout | Two-column layout, ruler, transport with icons, toolbar grouping, Banner, ShortcutSheet, table styling. | 5–6 days | Medium: `test_review_window` layout assumptions (`_LOOK_PANEL_WIDTH`, splitter) change; the Viewport, session and strip logic do not |
| D. Look + dialogs | Look panel re-flow, Episode strip, Export descriptions. | 2 days | Low |
| E. Polish | 150 ms disclosure animation (off under reduced motion), hover states, focus rings, Noto Sans Arabic as UI fallback, dark-mode contrast pass on every new colour with the existing `contrast_ratio` test helper. | 1–2 days | Low |

Ship A first on its own branch and look at it: tokens and icons alone move the
app from "prototype" to "product" and are reversible. B and C each follow the
existing phase-end review pattern (one whole-branch review, one fix wave).

## 6. Acceptance checks for the revamp

- Every screen passes 4.5:1 for text and 3:1 for controls in both themes (extend `tests/test_colors.py` to the new tokens).
- Nothing in the window is identified by colour alone (chips carry icons and text).
- Every icon button has an accessible name and a tooltip; focus ring visible on every control.
- Arabic: all new composites mirror; the ruler and clock stay LTR; no values-only Arabic line without a leading RLM (existing rule).
- The review window at 1280×800 shows at least eight caption rows in a lecture.
- A render's completion never blocks the window.
- Offscreen screenshot script re-run and the new images attached to the phase review.
