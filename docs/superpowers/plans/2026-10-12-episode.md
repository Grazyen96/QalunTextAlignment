# Episode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rendering a lecture also writes `<stem> – episode.mp4`: an optional intro clip, an optional recitation job's video, the lecture, and an optional outro clip, joined into one video. All choices are saved with the lecture project.

**Architecture:**
- The project gains an `episode` dict holding the intro, the recitation and the outro.
  - The intro and outro clips are copied beside the project.
  - The recitation is referenced by its project path.
- `jobs/episode.py` does the work:
  - it probes the parts;
  - it renders a stale recitation through `render_project`;
  - it joins everything in one FFmpeg `concat` filter run at the lecture's geometry.
- After the lecture render, `gui/jobs.run_render` calls it and writes shifted subtitle files.
- The review window gets an "Episode…" dialog. Its choices are an undoable session edit.

**Tech Stack:** Python 3.12, FFmpeg/ffprobe (found through `core.video_common.require_binary`), PySide6, pytest. pytest-qt is **not** installed, so GUI tests use the modules' helpers with `QT_QPA_PLATFORM=offscreen`.

**Spec:** `docs/superpowers/specs/2026-10-12-episode-design.md`

## Global Constraints

- Episode file: `<stem> – episode.mp4`, beside the lecture video. The separator is an en dash with spaces: `" – "`.
- Subtitle files: `<stem> – episode.<fmt>`. They hold the lecture's cues on the video timeline, shifted by `lecture_offset` = the sum of the durations of the parts before the lecture. They are written only when the job writes subtitle files.
- Clip types: `.mp4 .mov .mkv .webm`. Clips are copied to `<stem>.qalun.episode/<sha256[:12]><ext>` with `copy_by_content`, mode 0644. The recitation is referenced, never copied.
- Paths are stored relative to the project folder when inside it, otherwise absolute. This is the same rule as Look.
- `content_hash()` includes `episode` **only when it is non-empty**.
- A re-match keeps the earlier project's episode, as it already does for look and studied surah.
- Recitation part: reuse its recorded render when `recitation_needs_render` allows it (the job list calls it current, its file exists and it is not the lecture video just written). Otherwise render it first with its own job settings, its **own** subtitles choice and `formats=()`. (Ruling after Phase 1; it replaces "`render_is_stale` only" and `subtitles="sidecar"`.)
- Joining: one FFmpeg run.
  - Video per part: `scale=W:H:force_original_aspect_ratio=decrease,pad=W:H:(ow-iw)/2:(oh-ih)/2:black,setsar=1,fps=FPS,format=yuv420p`.
  - Audio per part: `aresample=48000,aformat=sample_fmts=fltp:channel_layouts=stereo`. A part with no audio gets `anullsrc=r=48000:cl=stereo` trimmed to its duration.
  - Then `concat=n=N:v=1:a=1`.
  - Encoding: `-c:v libx264 -preset veryfast -crf 18 -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart`, the frame renderer's settings.
- The output is written to `<output>.part.mp4` and renamed at the end. Failure or cancel removes the `.part` file.
- **If the lecture render succeeded, it is never undone by an episode failure.** The failure goes into `JobOutcome.episode_error`, a translated message.
- Lecture projects only: the button, the dialog and the render step all apply to lectures.
- Every string goes through `gui/i18n.py` in `en` and `ar`, and the Arabic strings are added to the native-speaker list in `docs/release-checklist.md`.
- Interpreter: `/home/khalil/PycharmProjects/QuranText/venv/bin/python`. Ad-hoc scripts need `PYTHONPATH=src`. Check `free -m` before the full suite. FFmpeg tests are skipped when FFmpeg is absent, using the existing skip marker pattern in `tests/test_video_renderer.py`.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never push.

## Review Focus

1. **A vertical phone intro (rotation metadata) before a landscape lecture.** It must be letterboxed upright, not sideways or stretched. Pinned by Task 2's `test_rotated_and_odd_sized_clips_are_letterboxed`.
2. **A clip with no audio track**, for example an exported title animation. The episode must still have continuous audio of the right length. Pinned by Task 2's `test_parts_without_audio_get_silence`.
3. **A recitation corrected after its last render.** The episode must use a fresh render, not the stale file. Pinned by Task 3's `test_a_stale_render_is_rendered_again`.
4. **Moving the lecture's folder to another disk.** The intro and outro must still be found. Pinned by Task 1's `test_episode_paths_survive_moving_the_folder`.
5. **Cancelling during the join.** No half-written episode is left, and the lecture video is kept. Pinned by Task 2's `test_cancel_removes_the_partial_file` and Task 4's `test_a_failed_episode_keeps_the_lecture`.

import json
import shutil
import subprocess
from pathlib import Path

import pytest

from qurantext.jobs.episode import EpisodeError, assemble_episode, episode_path_for, probe_part

pytestmark = pytest.mark.skipif(shutil.which("ffmpeg") is None, reason="needs FFmpeg")


def _make(path: Path, *, size="640x360", fps=25, seconds=1.0, audio=True, rotate=None) -> Path:
    cmd = ["ffmpeg", "-y", "-loglevel", "error",
           "-f", "lavfi", "-i", f"testsrc=size={size}:rate={fps}:duration={seconds}"]
    if audio:
        cmd += ["-f", "lavfi", "-i", f"sine=frequency=440:duration={seconds}"]
    cmd += ["-c:v", "libx264", "-pix_fmt", "yuv420p"]
    if audio:
        cmd += ["-c:a", "aac", "-shortest"]
    if rotate is not None:
        cmd += ["-metadata:s:v:0", f"rotate={rotate}"]  # newer FFmpeg: use -display_rotation on the input instead; report which works
    subprocess.run([*cmd, str(path)], check=True)
    return path


def _streams(path: Path) -> dict:
    out = subprocess.run(
        ["ffprobe", "-v", "error", "-show_streams", "-show_format", "-of", "json", str(path)],
        check=True, capture_output=True, text=True,
    ).stdout
    return json.loads(out)

`probe_part` runs `ffprobe -v error -show_streams -show_format -of json`. The duration is `format.duration`, falling back to the video stream's duration. `has_audio` is true when any stream has `codec_type == "audio"`.

`assemble_episode`:

```python
def _filter_graph(infos: list[PartInfo], width: int, height: int, fps: int) -> tuple[list[str], str]:
    """Extra lavfi inputs (silence for parts without audio) and the filter graph."""
    extra_inputs: list[str] = []
    chains: list[str] = []
    labels: list[str] = []
    silence_index = len(infos)
    for i, info in enumerate(infos):
        chains.append(
            f"[{i}:v:0]scale={width}:{height}:force_original_aspect_ratio=decrease,"
            f"pad={width}:{height}:(ow-iw)/2:(oh-ih)/2:black,setsar=1,fps={fps},format=yuv420p[v{i}]"
        )
        if info.has_audio:
            source = f"[{i}:a:0]"
        else:
            extra_inputs += ["-f", "lavfi", "-t", f"{info.duration:.3f}",
                             "-i", "anullsrc=r=48000:cl=stereo"]
            source = f"[{silence_index}:a:0]"
            silence_index += 1
        chains.append(
            f"{source}aresample=48000,aformat=sample_fmts=fltp:channel_layouts=stereo,"
            f"atrim=0:{info.duration:.3f},asetpts=PTS-STARTPTS[a{i}]"
        )
        labels.append(f"[v{i}][a{i}]")
    chains.append(f"{''.join(labels)}concat=n={len(infos)}:v=1:a=1[v][a]")
    return extra_inputs, ";".join(chains)
```

- **The command:** `ffmpeg -y -nostdin -progress pipe:1 -nostats`, then `-i part` for each part, then the extra inputs, then `-filter_complex graph -map [v] -map [a]` and the encoding arguments from Global Constraints, ending with `<output>.part.mp4`.
- **The run:** start it with `subprocess.Popen(stdout=PIPE, stderr=<temp file>, text=True)`. Read `out_time_us=` lines, call `report(progress, "episode", ...)` with the fraction, and check `cancel` between lines; on cancel, terminate, wait, delete `.part` and re-raise.
- **Failure:** on a non-zero exit, delete `.part` and raise `EpisodeError("episode.error.ffmpeg", reason=<last 5 lines of stderr>)`. On success, `replace` the `.part` file onto `output`.
- **The result:** `lecture_offset = sum(durations[:lecture_index])`.
- **Rotation:** FFmpeg autorotates on input by default; do **not** pass `-noautorotate`. If `test_rotated_and_odd_sized_clips_are_letterboxed` shows sideways output on this FFmpeg build, read the rotation from ffprobe's `side_data_list` and add `transpose`. Report which was needed.

Flow, after the lecture's `render_project` returns, in lecture projects with a non-empty episode:
1. Report `t("job.stage.episode_recitation")` and resolve the recitation with `recitation_video(...)`.
2. Build the parts list `[intro?, recitation?, result.video, outro?]` and record `lecture_index`. If it has only one entry, skip the episode.
3. Report `t("job.stage.episode_join")`, then call `assemble_episode(parts, episode_path_for(result.video), lecture_index=..., width, height, fps)`. The geometry comes from `project.render`, which `record_render` filled in.
4. If the job's subtitles choice writes files (`"sidecar"` or `"both"`) and formats are set, call `export_project_subtitles(project, episode stem, formats, timeline="video", offset=lecture_offset)`. The episode stem is `video_dir / f"{stem} – episode"`.
5. Record and save the episode in `project.render`.

Any `EpisodeError` sets `episode_error = t(err.key, **err.fmt)` and keeps the lecture outcome. (Ruling after the Phase 2 review, replacing "`JobCancelled` propagates": a cancel during the episode step sets `episode_error = t("episode.error.cancelled")` and any other error `t("episode.error.ffmpeg", reason=…)`, so the job finishes with the rendered lecture; the review window also takes the render record back on cancel and failure.) Subtitle files are named from the episode's full path, never from a stem `with_suffix` could cut at a dot.
