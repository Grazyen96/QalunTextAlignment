# Look (colour palettes and backgrounds) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the user choose a video's colours and background — six presets, individual colour pickers, built-in drawn backgrounds or their own image — in the review window with a live preview, saved per video with a default for new videos.

**Architecture:** A Qt-free `Look` value (`core/looks.py`) replaces the renderer's 13 hard-coded colours and is passed explicitly to every render call. `core/backgrounds.py` builds the frame's base layer (background + dim + blur + card panel) once per (look, size) and caches it, so each frame starts from a copy. The project's existing `style` slot stores the look; the review window's new Look panel edits it through the review session (undo, dirty, save), and the export, preview and CLI read it from there.

**Tech Stack:** Python 3.12, Pillow 10.2, NumPy, PySide6 (pytest-qt for GUI tests), pytest.

**Spec:** `docs/superpowers/specs/2026-10-11-look-design.md`

## Global Constraints

- With `look=NIGHT_GOLD` (or an empty project `style`), rendered frames are **byte-identical** to today's.
- Text contrast threshold: WCAG ratio **4.5:1**; the warning never blocks.
- Dim range **0–0.80** (default **0.35** when an image is chosen, **0** for built-ins); blur range **0–20**, radius `value × frame_height / 1000` px.
- Accepted image types: **PNG, JPEG, WebP**. Cover-fit (scale to fill, centre-crop), never stretch.
- Image copies go to `<project stem>.look/<sha256[:12]><ext>` beside the project file; stored **relative** to the project.
- `content_hash()` includes `style` **only when it is non-empty**.
- Base-layer cache: LRU of **4** entries.
- A missing or undecodable image never fails a preview or an export: fall back to the base preset's built-in background and report the warning code `image_missing` or `image_unreadable`.
- `core/` stays Qt-free. Every user-facing string goes through `gui/i18n.py` in **both** `en` and `ar`.
- Out of scope: video/animated backgrounds, fonts and sizes, per-card looks, intro/outro, SRT/ASS sidecar styling, the `ass` renderer mode.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never push.
- The laptop has limited RAM: check `free -m` before any full-video render; run one heavy job at a time.

# src/qurantext/core/looks.py
"""A video's look: its colours and its background, as one value.

The renderer used to read thirteen module constants. A ``Look`` carries the
same thirteen colours plus the background behind the card, and every render
call receives one, so the review window's preview and an export running at the
same moment can each draw their own. ``NIGHT_GOLD`` is exactly the old
constants, which is why a project that never chose a look renders as before.

No Qt here: the renderer and the jobs use this, and they import no Qt.
"""

from __future__ import annotations

import os
from dataclasses import asdict, dataclass, fields, replace
from pathlib import Path
from typing import Any

__all__ = [
    "BACKGROUND_KINDS",
    "COLOUR_FIELDS",
    "DEFAULT_PRESET",
    "EDITABLE_COLOURS",
    "IMAGE_SUFFIXES",
    "MAX_BLUR",
    "MAX_DIM",
    "MIN_CONTRAST",
    "NIGHT_GOLD",
    "PATTERN_KINDS",
    "PRESETS",
    "RGBA",
    "Background",
    "Look",
    "composite",
    "contrast_ratio",
    "look_from_style",
    "merge_style",
    "readability_warnings",
]

RGBA = tuple[int, int, int, int]

PATTERN_KINDS = ("pattern_stars", "pattern_lattice", "pattern_arches")
BACKGROUND_KINDS = ("solid", "gradient", *PATTERN_KINDS, "image")
IMAGE_SUFFIXES = (".png", ".jpg", ".jpeg", ".webp")
MAX_DIM = 0.8
MAX_BLUR = 20.0
#: WCAG 2.x minimum for normal text.
MIN_CONTRAST = 4.5
DEFAULT_PRESET = "night_gold"

#: The colours the Customise section offers; the rest follow the preset.
EDITABLE_COLOURS = (
    "body_text",
    "highlight_word",
    "header_text",
    "card",
    "caption_text",
    "caption_active",
)
#: Text drawn on the card, and text drawn on the caption strip: what the
#: readability check measures. Dimmed and debug text are dim on purpose.
_CARD_TEXT = ("header_text", "body_text", "highlight_word", "placeholder_text")
_CAPTION_TEXT = ("caption_text", "caption_active")


@dataclass(frozen=True, slots=True)
class Background:
    """What fills the frame behind the card.

    ``colour`` is the solid colour, the gradient's top, or a pattern's ground;
    ``colour2`` is the gradient's bottom or a pattern's line colour. ``dim``
    (0–0.8) lays black over it; ``blur`` (0–20) is a Gaussian radius of
    ``blur × frame_height / 1000`` pixels.
    """

    kind: str
    colour: RGBA
    colour2: RGBA
    image: Path | None = None
    dim: float = 0.0
    blur: float = 0.0


@dataclass(frozen=True, slots=True)
class Look:
    frame_bg: RGBA
    card: RGBA
    card_border: RGBA
    header_text: RGBA
    body_text: RGBA
    highlight_word: RGBA
    subtle: RGBA
    debug_text: RGBA
    placeholder_text: RGBA
    caption_bg: RGBA
    caption_text: RGBA
    caption_active: RGBA
    caption_upcoming: RGBA
    background: Background
    base_preset: str = DEFAULT_PRESET

    @property
    def is_preset(self) -> bool:
        return PRESETS.get(self.base_preset) == self

    def to_dict(self, relative_to: Path | None = None) -> dict[str, Any]:
        bg = self.background
        return {
            "preset": self.base_preset,
            "colours": {name: _hex(getattr(self, name)) for name in COLOUR_FIELDS},
            "background": {
                "kind": bg.kind,
                "colour": _hex(bg.colour),
                "colour2": _hex(bg.colour2),
                "image": _store_path(bg.image, relative_to) if bg.image else None,
                "dim": round(bg.dim, 3),
                "blur": round(bg.blur, 3),
            },
        }

    @classmethod
    def from_dict(cls, data: Any, *, base_dir: Path | None = None) -> Look:
        if not isinstance(data, dict):
            return NIGHT_GOLD
        preset_name = data.get("preset")
        base = PRESETS.get(preset_name) if isinstance(preset_name, str) else None
        if base is None:
            base = NIGHT_GOLD
        colours = data.get("colours") if isinstance(data.get("colours"), dict) else {}
        updates = {
            name: parsed
            for name in COLOUR_FIELDS
            if (parsed := _parse_hex(colours.get(name))) is not None
        }
        background = _parse_background(data.get("background"), base.background, base_dir)
        return replace(base, **updates, background=background)


def _parse_background(data: Any, fallback: Background, base_dir: Path | None) -> Background:
    if not isinstance(data, dict):
        return fallback
    kind = data.get("kind")
    if kind not in BACKGROUND_KINDS:
        return fallback
    image = None
    if kind == "image":
        raw = data.get("image")
        if not isinstance(raw, str) or not raw:
            return fallback
        image = _resolve_path(raw, base_dir)
    return Background(
        kind=kind,
        colour=_parse_hex(data.get("colour")) or fallback.colour,
        colour2=_parse_hex(data.get("colour2")) or fallback.colour2,
        image=image,
        dim=_clamped(data.get("dim"), 0.0, MAX_DIM, fallback.dim),
        blur=_clamped(data.get("blur"), 0.0, MAX_BLUR, fallback.blur),
    )


def _hex(colour: RGBA) -> str:
    return "#" + "".join(f"{channel:02X}" for channel in colour)


def _parse_hex(value: Any) -> RGBA | None:
    if not isinstance(value, str) or len(value) not in (7, 9) or not value.startswith("#"):
        return None
    try:
        channels = [int(value[i : i + 2], 16) for i in range(1, len(value), 2)]
    except ValueError:
        return None
    if len(channels) == 3:
        channels.append(255)
    return tuple(channels)  # type: ignore[return-value]


def _clamped(value: Any, low: float, high: float, fallback: float) -> float:
    if isinstance(value, bool) or not isinstance(value, (int, float)):
        return fallback
    return float(min(high, max(low, value)))

        except ValueError:  # another drive on Windows

def _linear(channel: int) -> float:
    c = channel / 255
    return c / 12.92 if c <= 0.04045 else ((c + 0.055) / 1.055) ** 2.4


def _luminance(colour: tuple[int, ...]) -> float:
    r, g, b = (_linear(c) for c in colour[:3])
    return 0.2126 * r + 0.7152 * g + 0.0722 * b


def contrast_ratio(fg: tuple[int, ...], bg: tuple[int, ...]) -> float:
    """WCAG 2.x contrast ratio of two opaque colours (alpha is ignored)."""
    high, low = sorted((_luminance(fg), _luminance(bg)), reverse=True)
    return (high + 0.05) / (low + 0.05)


def composite(fg: RGBA, bg: tuple[int, ...]) -> tuple[int, int, int]:
    """*fg* laid over an opaque *bg* at its alpha."""
    alpha = fg[3] / 255
    return tuple(round(fg[i] * alpha + bg[i] * (1 - alpha)) for i in range(3))  # type: ignore[return-value]

# src/qurantext/core/backgrounds.py
"""The part of every frame that does not change: the background and the card panel.

A frame used to start as a flat colour with the card composited onto it from a
fresh full-size overlay, every frame. Now the background may be a gradient, a
drawn pattern or a photo (cover-fitted, blurred, dimmed), which is far too
much to redo per frame, and none of it changes during a render. So the layer
is built once per (look, frame size, card box) and every frame starts from a
copy of it.

A photo that is missing or unreadable never stops a render: the look's preset
background is drawn instead and the layer carries a warning code for the
caller to show.
"""

from __future__ import annotations

from collections import OrderedDict
from dataclasses import dataclass, replace
from pathlib import Path

from PIL import Image, ImageDraw, ImageFilter, ImageOps, ImageStat, UnidentifiedImageError

from qurantext.core.looks import PRESETS, Background, Look, NIGHT_GOLD

__all__ = ["BaseLayer", "background_mean", "base_layer", "clear_cache"]

_CACHE_SIZE = 4
_cache: OrderedDict[tuple, BaseLayer] = OrderedDict()


@dataclass(frozen=True, slots=True)
class BaseLayer:
    #: Shared between frames: copy before drawing on it.
    image: Image.Image
    #: The background's average colour, before the card: what the card sits on.
    mean: tuple[int, int, int]
    warnings: tuple[str, ...] = ()


def clear_cache() -> None:
    _cache.clear()


def _image_stamp(background: Background) -> tuple[int, int] | None:
    if background.kind != "image" or background.image is None:
        return None
    try:
        stat = background.image.stat()
    except OSError:
        return None
    return (stat.st_size, stat.st_mtime_ns)


def base_layer(
    look: Look, width: int, height: int, card_box: tuple[int, int, int, int], radius: int
) -> BaseLayer:
    key = (look, width, height, card_box, radius, _image_stamp(look.background))
    layer = _cache.get(key)
    if layer is not None:
        _cache.move_to_end(key)
        return layer
    background, mean, warnings = _background_or_fallback(look, width, height)
    image = background.copy()
    _draw_card(image, card_box, radius, look.card, look.card_border)
    layer = BaseLayer(image=image, mean=mean, warnings=warnings)
    _cache[key] = layer
    while len(_cache) > _CACHE_SIZE:
        _cache.popitem(last=False)
    return layer


def background_mean(look: Look, width: int, height: int) -> tuple[int, int, int]:
    return _background_or_fallback(look, width, height)[1]


def _background_or_fallback(
    look: Look, width: int, height: int
) -> tuple[Image.Image, tuple[int, int, int], tuple[str, ...]]:
    warnings: tuple[str, ...] = ()
    try:
        image = _draw_background(look.background, width, height)
    except _ImageProblem as problem:
        warnings = (problem.code,)
        fallback = PRESETS.get(look.base_preset, NIGHT_GOLD).background
        if fallback.kind == "image":  # a preset never has one; belt and braces
            fallback = NIGHT_GOLD.background
        image = _draw_background(fallback, width, height)
    mean = tuple(int(round(c)) for c in ImageStat.Stat(image.convert("RGB")).mean)
    return image, mean, warnings  # type: ignore[return-value]


class _ImageProblem(Exception):
    def __init__(self, code: str) -> None:
        super().__init__(code)
        self.code = code


def _draw_background(background: Background, width: int, height: int) -> Image.Image:
    kind = background.kind
    if kind == "solid":
        # NIGHT_GOLD's solid colour is the old COLOUR_BG, so this is the old frame fill.
        image = Image.new("RGBA", (width, height), background.colour)
    elif kind == "gradient":
        image = _gradient(background.colour, background.colour2, width, height)
    elif kind == "image":
        image = _photo(background.image, width, height)
    else:
        image = Image.new("RGBA", (width, height), background.colour)
        _PATTERNS[kind](ImageDraw.Draw(image), background.colour2, width, height)
    if background.blur > 0:
        image = image.filter(ImageFilter.GaussianBlur(background.blur * height / 1000))
    if background.dim > 0:
        shade = Image.new("RGBA", (width, height), (0, 0, 0, int(round(background.dim * 255))))
        image.alpha_composite(shade)
    return image


def _gradient(top, bottom, width: int, height: int) -> Image.Image:
    mask = Image.linear_gradient("L").resize((width, height))
    return Image.composite(
        Image.new("RGBA", (width, height), bottom), Image.new("RGBA", (width, height), top), mask
    )


def _photo(path: Path | None, width: int, height: int) -> Image.Image:
    if path is None or not path.is_file():
        raise _ImageProblem("image_missing")
    try:
        with Image.open(path) as source:
            source.load()
            rgb = ImageOps.exif_transpose(source).convert("RGB")
    except (UnidentifiedImageError, OSError, ValueError, Image.DecompressionBombError):
        raise _ImageProblem("image_unreadable") from None
    fitted = ImageOps.fit(rgb, (width, height), method=Image.Resampling.LANCZOS)
    return fitted.convert("RGBA")


def _line_width(height: int) -> int:
    return max(1, height // 540)


def _stars(draw: ImageDraw.ImageDraw, colour, width: int, height: int) -> None:
    """Eight-point stars (two overlaid squares) on a square grid."""
    cell = max(24, height // 9)
    r = cell * 0.32
    d = r * 1.414
    lw = _line_width(height)
    for cy in range(cell // 2, height + cell, cell):
        for cx in range(cell // 2, width + cell, cell):
            square = [(cx - r, cy - r), (cx + r, cy - r), (cx + r, cy + r), (cx - r, cy + r)]
            diamond = [(cx, cy - d), (cx + d, cy), (cx, cy + d), (cx - d, cy)]
            for shape in (square, diamond):
                draw.line([*shape, shape[0]], fill=colour, width=lw, joint="curve")


def _lattice(draw: ImageDraw.ImageDraw, colour, width: int, height: int) -> None:
    """Diagonal lines both ways: a lattice of diamonds."""
    cell = max(24, height // 12)
    lw = _line_width(height)
    for k in range(-height, width + height, cell):
        draw.line([(k, 0), (k + height, height)], fill=colour, width=lw)
        draw.line([(k, height), (k + height, 0)], fill=colour, width=lw)


def _arches(draw: ImageDraw.ImageDraw, colour, width: int, height: int) -> None:
    """Rows of round arches on columns."""
    cell = max(24, height // 10)
    lw = _line_width(height)
    for y in range(cell, height + cell, cell):
        for x in range(0, width + cell, cell):
            draw.arc((x, y - cell, x + cell, y), start=180, end=360, fill=colour, width=lw)
            draw.line([(x, y - cell // 2), (x, y)], fill=colour, width=lw)


_PATTERNS = {"pattern_stars": _stars, "pattern_lattice": _lattice, "pattern_arches": _arches}


def _draw_card(image: Image.Image, box, radius: int, fill, outline) -> None:
    """The card panel, drawn exactly as frame_renderer.draw_rounded_rectangle drew it."""
    overlay = Image.new("RGBA", image.size, (0, 0, 0, 0))
    ImageDraw.Draw(overlay, "RGBA").rounded_rectangle(
        box, radius=radius, fill=fill, outline=outline, width=2
    )
    image.alpha_composite(overlay)

# src/qurantext/jobs/project.py — content_hash
    def content_hash(self) -> str:
        """A digest of what a render depends on: the cards, the captions and a chosen look.

        The look joins the digest only once one is chosen, so a project from
        before looks existed keeps its hash and its render stays current.
        """
        content: dict[str, Any] = {
            "cards": self.cards,
            "captions": [cue.to_dict() for cue in self.captions],
        }
        if self.style:
            content["style"] = self.style
        payload = json.dumps(content, sort_keys=True, ensure_ascii=False, default=str)
        return hashlib.sha256(payload.encode("utf-8")).hexdigest()

# src/qurantext/jobs/look_assets.py
"""Where a project's look lives on disk: its style entry and its background image.

The person's image is copied next to the project, named by its content, so the
project folder can be moved or shared with the image inside it, and choosing
the same photo twice keeps one copy.
"""

from __future__ import annotations

import hashlib
import shutil
from pathlib import Path

from qurantext.core.looks import IMAGE_SUFFIXES, NIGHT_GOLD, Look, look_from_style, merge_style
from qurantext.jobs.project import Project

__all__ = ["import_look_image", "look_dir_for", "project_look", "set_project_look"]


def look_dir_for(project_path: Path) -> Path:
    return Path(project_path).with_suffix(".look")


def _project_dir(project: Project) -> Path:
    return Path(project.path).parent if project.path is not None else Path.cwd()


def project_look(project: Project) -> Look:
    return look_from_style(project.style, base_dir=_project_dir(project))


def set_project_look(project: Project, look: Look) -> None:
    if look == NIGHT_GOLD and not project.style:
        return
    project.style = merge_style(project.style, look, relative_to=_project_dir(project))


def import_look_image(project_path: Path, source: Path) -> Path:
    source = Path(source).expanduser()
    suffix = source.suffix.lower()
    if suffix not in IMAGE_SUFFIXES:
        raise ValueError(f"{source.name}: choose a PNG, JPEG or WebP image.")
    if not source.is_file():
        raise FileNotFoundError(source)
    digest = hashlib.sha256(source.read_bytes()).hexdigest()[:12]
    folder = look_dir_for(project_path)
    destination = (folder / f"{digest}{suffix}").resolve()
    if not destination.is_file():
        folder.mkdir(parents=True, exist_ok=True)
        temporary = destination.with_suffix(destination.suffix + ".part")
        shutil.copyfile(source, temporary)
        temporary.replace(destination)
    return destination

    # The look new videos start with. Stored with an absolute image path into the

    @property
    def default_look(self) -> Look:
        raw = self._settings.value("default_look", "")
        if not isinstance(raw, str) or not raw:
            return NIGHT_GOLD
        try:
            return look_from_style(json.loads(raw))
        except ValueError:
            return NIGHT_GOLD

    def save_default_look(self, look: Look) -> Look:
        bg = look.background
        if bg.kind == "image" and bg.image is not None:

            look = replace(look, background=replace(bg, image=copied))

        self._settings.sync()
        return look

    def default_look_style(self) -> dict:
